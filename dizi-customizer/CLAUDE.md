# 项目名称：交互式3D竹笛定制工具 V2.0

## 1. 核心目标
使用 JavaScript 和 Three.js 开发一个纯前端、基于网页的3D工具。此工具允许用户对一个中国竹笛（Dizi）的3D模型进行个性化定制，并支持两种独立模式：
- **视觉模式 (Visual Mode):** 应用图像和文字纹理，用于数字艺术展示。
- **打印模式 (Print Mode):** 通过浮雕/雕刻修改模型几何体，用于生成可3D打印的模型。
最终成品将通过 iFrame 嵌入到一个 Wix 个人作品集网站。

## 2. 关键技术栈
- **核心语言:** JavaScript (ES6+)
- **3D渲染库:** Three.js
- **几何运算库 (用于打印模式):** `three-csg-ts`，用于执行网格的布尔运算。
- **用户界面:** 标准 HTML5 和 CSS3。除非绝对必要，否则不使用复杂的前端框架。
- **核心资产:** 一个预先制作好的 `dizi_model.glb` 模型，位于 `/assets/` 目录中。

## 3. 资产规格: `dizi_model.glb`
- **UV展开:** 模型已拥有清晰的 UV，用于在视觉模式下进行纹理贴图。
- **水密/流形:** 几何体是封闭且有效的，以确保CSG布尔运算的成功率。
- **材质组:** 模型包含至少两个独立的材质组，分别对应"图案区域" (Pattern Area) 和"文字区域" (Text Area)，以便进行定向定制。**我会在稍后告知您这两个材质的具体名称。**

## 4. 高阶功能分解
- **FR-01 & FR-02:** 加载 `dizi_model.glb` 并启用轨道控制器（旋转、平移、缩放）。
- **FR-03:** 实现一个UI切换控件，用于在 `Visual Mode` 和 `Print Mode` 之间切换。此切换将控制后续的定制逻辑。
- **FR-04 (视觉模式):**
  - **图像贴图:** 文件上传功能，将图片作为纹理应用到"图案区域"。
  - **文字贴图:** 文本输入功能，动态生成文字纹理并应用到"文字区域"。
- **FR-05 (打印模式):**
  - **图像浮雕/雕刻:** 上传黑白图片或SVG，将其转换为3D网格，并与竹笛主模型进行布尔运算（并集或差集）。提供滑块控制深度/高度。
  - **文字浮雕/雕刻:** 将输入文字生成为3D网格，并与主模型进行布尔运算。提供滑块控制深度/高度。
- **FR-06:** 所有定制操作都必须实时在3D视图中预览。
- **FR-07:** 实现模型导出功能。
  - **视觉模式下:** 导出带纹理的 `.glb` 文件。
  - **打印模式下:** 导出几何体已修改的 `.stl` 或 `.glb` 文件。

## 5. 文件结构
- `index.html`: 应用的HTML骨架。
- `styles.css`: 界面样式。
- `main.js`: Three.js 和所有应用逻辑的核心文件。
- `/assets/dizi_model.glb`: 3D模型。
